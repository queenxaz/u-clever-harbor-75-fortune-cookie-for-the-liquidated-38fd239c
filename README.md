A fortune for the liquidated trader: you will lose every coin you chase — but the moon you keep missing was never yours to catch, dear trader.

## The entry

> You will lose every coin you chase. But the moon you keep missing was never yours to catch, dear trader.

(104 characters, limit 160, 20 words.)

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.

```sh
python3 main.py
cat /output/entry.txt
```
